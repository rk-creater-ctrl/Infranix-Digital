Maintenance FAQs

Yes, if the files or GitHub repository access is available and the scope is clear.

Can you rebuild only the design?

Yes. The content can stay similar while the layout, spacing, buttons, sections, and mobile design are improved.

Can I ask for one small change?

Yes. Small feature additions and bug fixes are available as separate low-cost tasks.
